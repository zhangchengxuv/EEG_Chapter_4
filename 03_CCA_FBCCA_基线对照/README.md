# 4.2 SSVEP 识别算法补充与跨天对比实验

本目录存放基于远程主机训练成果（`02_gNautilus` 与 `01_ADS1299`）及本地补跑的无训练 CCA/FBCCA 基准实验的代码、汇总指标、论文插图与第 4 章正文初稿。

## 目录结构

- `01_CCA基线与统计代码/`
  - `run_cca_baseline.py`：在 g.Nautilus（95 固定测试 / 339 全部）与 ADS1299（首日 544 / 测试 128、次日跨天 128）上运行标准 CCA（$N_h=1,2,3$）与 3 子带 FBCCA 及窗长扫描。
  - `run_fbcca_window_and_445_check.py`：检验 `4.2.2` 连续 `4–45 Hz (μV)` 口径下的 CCA/FBCCA，并扫描 FBCCA 在 1.0–3.0 s 时间窗长下的准确率与 ITR。
  - `plot_thesis_figures.py`：严格读取真实 JSON/CSV 生成统一白底低饱和蓝青灰风格的 `Fig_4_30` 至 `Fig_4_34`（300 dpi PNG + SVG）。
- `02_实验结果汇总/`：上述脚本输出的 CSV/JSON 数值汇总。
- `03_论文插图重绘/`：对应正文 `图4-30` 至 `图4-34` 的 300 dpi PNG 与 SVG 文件。
- `04_论文章节文稿与问题记录/`
  - `4.2.3_4.2.4_4.4.1_论文正文初稿.md`：包含 `4.2.2` 最小衔接建议及 `4.2.3`、`4.2.4`、`4.4.1` 完整审阅初稿。
  - `MathType_LaTeX公式对照.md`：`式(4-11)` 至 `式(4-20)` 的 LaTeX 对照代码。
  - `未决技术问题记录.md`：影响结论与待确认的技术问题及待插 Zotero 文献清单。
