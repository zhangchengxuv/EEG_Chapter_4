## 结论与仍存在的限制

同一个冻结模型在旧内部测试会话是128/128，今天新增会话是88/128。**旧内部测试的100%没有保持到今天的独立采集上。** 仅凭这一次结果不能确定下降全部来自过拟合、记录分布变化、参考/噪声、同步或处理差异中的哪一项。

按NPZ事件顺序比较，今天128个标签的顺序与旧数据中三个完整128试次run完全相同。虽然是跨天独立采集，固定刺激顺序的问题仍未解决；这份结果不能当成“已换随机顺序”的验证。

新文件没有附带单独的metadata.json或连续原始记录。单位、通道、采样率、数组长度和标签可由NPZ核查；0.5～3.5秒窗口依据文件名与用户说明，无法仅凭本文件独立核验其上游滤波、事件对齐和物理刺激边界与旧包完全一致。
