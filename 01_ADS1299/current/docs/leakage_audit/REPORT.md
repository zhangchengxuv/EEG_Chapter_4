# ADS1299 满分结果的泄漏、过拟合与实验混淆审计

审计对象始终是 `ADS1299_20261116_combined4Recordings_allTrials_500Hz_0p5to3p5s_V.npz`：544 个试次，前两次采集训练 288、第三次验证 128、第四次测试 128。单次文件只用于来源哈希核对，没有再次加入训练。

**结论：在已检查的加载和训练流程中未发现直接泄漏；但发现固定刺激顺序这一明确的实验设计限制，因此不能把当前 128/128 解读为已经证明无过拟合或新顺序下也有 100% 准确率。** 本次没有因审计结果调整生产模型、筛选试次或重新选择参数。

## 已核查的训练流程

- 会话和 run 均完整划分，没有分散到训练、验证、测试多个集合。
- 544 个 trial_id 唯一，544 个原始信号内容哈希也唯一。
- 验证/测试与训练试次的最大绝对零时移相关系数分别为 0.5184、0.5523；未见此检查范围内的近乎完全复制。这个检查不等于排除所有移位复制或上游生成问题。
- 通道和频谱标准化仅拟合训练集，验证及测试只应用训练统计量。
- 最终 EEGNet 只输入信号及不使用的全零频谱占位张量，没有输入 y、刺激频率、trial_id、run/session 或试次位置。
- 检查点、架构、单模型/集成均在测试前通过验证集选择；测试记录没有用于继续调参。
- 原数据包所有已记录文件及三份原训练代码的 SHA256 均与训练前一致。
- 推理使用评估模式，Dropout 关闭，BatchNorm 不更新训练统计量。

## 核心限制：相同刺激顺序跨 run 重复

按元数据 `protocol_trial` 建立“run 内位置→标签”的查表，只使用训练会话中的位置和标签：

| 无 EEG 的位置查表 | 正确/总数 | 准确率 |
| --- | ---: | ---: |
| 验证 | 128/128 | 100% |
| 测试 | 128/128 | 100% |

每个 run 内位置在训练数据中只有一个对应类别，验证和测试复用了相同映射。这说明**会话彼此独立，并不代表类别与实验顺序也独立**。

EEGNet 没有输入位置，打乱推理批次顺序也不改变预测，因此上述结果不能证明 EEGNet 实际使用了位置。需要警惕的是信号中的位置相关变化、固定序列相关响应或刺激设备伪迹。现有包不能确定它们贡献多少，也不能仅凭监督分类证明模型识别的全部是神经源 SSVEP。

跨 run 但刺激顺序相同的时间混淆在其他 EEG 解码任务已有直接实验研究，见 [Ahmed 等：Confounds in the Data](https://pmc.ncbi.nlm.nih.gov/articles/PMC9719395/)。该论文研究的是视觉类别解码，不是本次 SSVEP；这里引用它作为方法学依据，不能用它替代对本数据的因果验证。

## 已完成的负对照

以下 EEGNet 对照均使用验证会话，不重新选择模型或训练轮次：

| 条件 | 验证结果 |
| --- | ---: |
| 原冻结模型、真实信号及真实标签 | 128/128，100% |
| 打乱输入顺序后再恢复原顺序 | 概率最大差值 0，全部预测一致 |
| 所有输入置零 | 32/128，25% |
| 独立白噪声；幅度只由训练数据估计 | 30/128，23.4375% |
| 独立打乱训练标签后，从头训练相同架构 | 18/128，14.0625% |

打乱标签控制固定使用一次排列（种子 271828）、权重初始化种子 42、相同优化器与批量、固定训练 293 轮。训练过程中不计算验证成绩，也不按对照验证成绩选择轮次。对照模型对随机训练标签的拟合准确率为 275/288=95.4861%。

这些结果不支持程序直接读取真实标签、按输入批次位置直接给答案或无信号也能满分的解释。随机标签模型能高度拟合训练集而无法泛化，说明模型有记忆能力；但不能据此断言原真实标签模型已过拟合，也不能由一次随机置换证明所有泄漏均不存在。这不是多次置换检验，没有据此计算显著性。

## 关于过拟合的准确表述

冻结的原模型在同一评估模式下：训练 288/288，验证 128/128，保存的测试记录为 128/128；训练、验证、测试交叉熵约为 0.001216、0.002449、0.009711。

当前没有出现“训练准确率很高，留出会话准确率明显下降”的常见现象，但这不能排除模型拟合了所有会话共同的实验协议。十组候选、最多 300 轮及三个种子的选择也会让验证成绩乐观；保留测试会话缓解了直接的验证选型偏差，却没有消除共享顺序的设计限制。

## 尚未独立核查的部分

当前包包含处理后的 NPZ、元数据及来源核验记录，没有提供原始连续 CSV/FIF 和刺激程序。因而尚未独立复算采集→滤波→事件对齐→切窗→导出的全部上游过程，不能把包内既有的验证 JSON 当成独立证据。未知软硬件延迟、神经信号与设备干扰的区分也尚未完成。

更有判别力的下一步是：冻结当前模型和全部预处理，用**新随机种子生成不同刺激顺序**，另采同一人的新会话并直接盲测，最好覆盖不同日期。同时独立核对刺激程序与原始连续数据，必要时做光电同步和设备干扰对照。只在现有相同顺序数据上反复换随机划分或继续调参，不能充分解决此问题。
