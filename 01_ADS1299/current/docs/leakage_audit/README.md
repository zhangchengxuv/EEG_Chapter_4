详细数据见 `REPORT.md` 与 `audit.json`。报告末尾的历史复现命令原本用于父目录的旧工程；原脚本快照在本目录的 `provenance/original_code/`。本次独立重跑不再次训练随机标签对照模型，也不将它作为最终模型。
