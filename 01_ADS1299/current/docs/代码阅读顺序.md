# 代码阅读顺序

本轮只复现已经选定的 EEGNet-16,2 长时间核配置，不搜索其他架构，不读取历史权重继续训练。

1. `run_all.py`：启动本目录内的两个独立步骤，保存各自日志。先训练 ADS1299，再进行 g.Nautilus 外部复测。
2. `code/train.py`：七步主流程，保存分组、来源、参数、模型和最终测试结果。
3. `code/training.py`：真正的训练循环。每批清空梯度、计算交叉熵、反向传播、限制梯度、更新参数及施加权重范数约束；每轮只查看验证成绩。
4. `code/ads1299_models.py`：网络定义。文件保留历史兼容分支，本轮配置只启用 `standard` 时域分支。
5. `code/ads1299_data.py`：校验合并数据、按完整会话划分、单位转换、重采样、训练集统计量及指标。
6. `code/test_gnautilus.py`：冻结本轮模型后，读取另一设备的历史信号，单独输出跨设备结果。
7. `code/predict.py`：对新的 ADS1299 信号无标签预测。`code/plots.py` 负责全部中文图像。

## 本轮网络张量形状

| 步骤 | 输出形状 | 含义 |
| --- | --- | --- |
| 原始 ADS1299 输入 | `[N,8,1500]` | N个独立试次、8通道、500Hz下3秒；单位V |
| 固定预处理 | `[N,1,8,750]` | 转μV，降至250Hz，再按训练统计量标准化 |
| 时间卷积 | `[N,16,8,750]` | 16个长度251点的时间滤波器 |
| 深度空间卷积 | `[N,32,1,750]` | 每个时间滤波器学习两个跨8通道空间滤波器 |
| 第一次平均池化 | `[N,32,1,187]` | 时间维除以4，向下取整 |
| 可分离卷积 | `[N,32,1,187]` | 各特征图独立时间卷积，再用1×1卷积融合 |
| 第二次平均池化 | `[N,32,1,23]` | 时间维再除以8 |
| 展平与线性层 | `[N,4]` | 736维特征映射为四类logits |

网络输出的 logits 先交给交叉熵进行训练；推理时再用 softmax 转换为四类概率。

## 预处理与信息边界

数据处理中的均值、标准差只用 ADS1299 训练会话拟合。验证集只选择训练轮次；测试会话在模型固化后才推理。采集编号、试次编号和标签只用于对齐、划分或输出，不是预测输入。

g.Nautilus 原信号已经是 μV、250Hz，直接裁剪原0～4秒窗口中的 `[125:875]`，对应0.5～3.5秒共750点，然后应用 ADS1299 训练统计量。不能将它再次乘1e6，也不能在外部信号上重新拟合标准化后仍称为同一冻结模型。

## 历史限制

相同刺激顺序跨run重复的问题并未因重新训练或更换目录而解决。外部设备数据同样是已有历史数据，跨设备复测不等于新随机顺序的盲测。完整历史审计归档在 `docs/leakage_audit/`。
