# ADS1299 同一受试者 EEGNet 四分类

本目录仅使用自制 ADS1299 采集的四次记录，按用户确认解释为同一个人的数据。训练不混入 g.Nautilus 数据，数据包 `SSVEP_ML_Dataset/` 保持原样。模型选择、数据划分、运行版本和结果均保留文件记录。

**后续审计的重要限制：** 四次采集的五个 run 复用同一套刺激顺序；仅用训练数据建立“run 内试次位置→类别”查表，不看 EEG 也能在验证和测试上达到 100%。模型没有输入试次位置，因此这不是它利用顺序作弊的直接证明，但现有设计不能充分排除顺序及其相关线索的混淆。下文 100% 仅代表当前拆分的实际观察，不能解释为已经证明无泄漏、无过拟合或可泛化到新顺序。详见 [泄漏与混淆审计](results/leakage_audit_20261117/REPORT.md)。

## 本次实际训练结果

最终模型是 **EEGNet-16,2 长时间核版本**：16 个时间滤波器，时间核 251 点（内部 250 Hz），每个时间滤波器对应两个空间滤波器，随后使用可分离卷积和四分类层。采用种子 42，第 293 轮的检查点。没有启用能量分类头、频谱分支或额外 4～45 Hz 带通。

| 模型 | 验证准确率 | 验证交叉熵 | 测试正确/总数 | 测试准确率 | 测试宏 F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原始 EEGNet 基线 | 100% | 0.006548 | 128/128 | 100% | 1.0000 |
| 最终长时间核 EEGNet | **100%** | **0.002449** | **128/128** | **100%** | **1.0000** |

四个测试类别均为 32/32 正确，精确率、召回率和 F1 均为 1。测试会话中的两个质量标记试次全部保留在主指标内。原始基线已经达到满分，本次不能宣称提高了测试准确率；最终模型的验证交叉熵更低。

最终参数：AdamW 学习率 0.0005、weight decay 0.01、批量 32、Dropout 0.5、BatchNorm momentum 0.1、最大 300 轮，早停等待 60 轮。空间滤波器最大范数 1.0，分类器最大范数 0.25。

同一架构的固定种子 42、43、44 均达到验证集 128/128。三模型概率平均同为 100%，但验证交叉熵为 0.003041，高于种子 42 的单模型，故最终使用单模型。上述选择均在读取测试成绩前固化。

该测试是当前同一人、同一天实验中独立保留的一个会话；不等于跨受试者、跨设备或跨天泛化结果。与上一批 g.Nautilus 实验的数据和划分均不同，不直接比较两种设备的准确率。

## 运行方式

在本目录运行，复现最近一次实验选定的模型及随机种子：

```bash
.venv/bin/python train_ads1299.py --final-only
```

重新执行完整的十组候选搜索：

```bash
.venv/bin/python train_ads1299.py
```

两种方式都会新建带时间戳的目录，不覆盖已有结果。`--final-only` 不重新搜索模型，仅在固定验证会话选择训练轮次；它需要本目录已有 `latest_run.txt` 和对应模型。本次首次实验目录为 `results/ads1299_session_search/`。

对新的同定义信号做无标签推理：

```bash
.venv/bin/python predict_ads1299.py \
  --input 你的新信号.npz \
  --output results/new_predictions.csv
```

默认加载最近完成的模型；也可传入 `--model results/ads1299_session_search/selected_model/model.pt`。输入 NPZ 必须含 `X`，形状 `[N,8,1500]`、单位 **V**、500 Hz、软件 Marker 后 `[0.5,3.5)` 秒。通道顺序与下表一致；`trial_ids` 可选。推理不读取 y、真实刺激频率、采集编号或其他类别元数据。

| --- | ---: | --- | ---: | ---: |

标签始终表示提示注视目标，不表示机器人实际执行动作。

## 预处理和模型选择

1. 将 V 转为 μV 一次，随后用带抗混叠 FIR 的多相重采样从 500 Hz 降为 250 Hz。时间窗口仍是同一个 3 秒试次，变成 750 点，不增加样本。
2. 每个试次独立处理，不拼接试次来滤波。部分候选额外采用四阶 Butterworth 4～45 Hz 零相位频带限制；这是本轮候选超参数，不是对原始处理状态的改写。
3. 每通道标准化的均值、标准差仅在 288 个训练试次上拟合，验证和测试沿用训练统计量。需要频谱标准化时同样只拟合训练集。
4. 对十组预定候选使用种子 42：原版 EEGNet、长时间核 EEGNet、五种能量汇聚配置、两种频谱消融模型、一种能量＋频谱融合模型。
5. 以验证准确率优先、交叉熵次优选择轮次及 EEGNet 类架构，纯频谱候选只作消融。再用固定种子 43、44 检查同一架构，并在验证集比较种子 42 单模型与三模型概率平均。
6. 先保存 `selection_before_test.json` 和最终权重，再对测试会话评估。所有试次保留，未根据测试成绩选择滤波、阈值、模型或种子。

默认最多 300 轮，连续 60 轮没有更好的验证选择分数则早停，批量 32，AdamW，梯度范数限制 5。各候选学习率、weight decay、时间核长度、滤波器数及频带见 `train_ads1299.py` 开头的 `CANDIDATES` 和实验的 `search_plan.json`。

原版 EEGNet 使用时间卷积、深度空间卷积、可分离卷积和四分类层。能量变体保留时空卷积，以平方、时间均值、对数和线性分类层替代可分离卷积头，属于衍生模型。融合候选再加入固定四个候选目标的基频、二次和三次谐波信噪比；特征全部从 EEG 计算，不输入单个试次的真实刺激频率。

参考：[EEGNet 作者实现](https://github.com/vlawhern/arl-eegmodels/blob/master/EEGModels.py)、[SciPy 多相重采样](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample_poly.html)、[SciPy 双向 SOS 滤波](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfiltfilt.html)。

## 代码及结果文件

| 文件 | 用途 |
| --- | --- |
| `train_ads1299.py` | 主入口：固定划分、训练、验证选型、最终测试；也支持只训练最终配置 |
| `ads1299_models.py` | EEGNet 与变体定义，含中文逐步注释 |
| `ads1299_data.py` | 数据核验、V 单位处理、重采样、训练统计量、指标和绘图 |
| `predict_ads1299.py` | 读取保存模型，对无标签信号预测 |
| `tests/test_training.py` | 分组、单位、元数据、预处理及模型接口检查 |

每个结果目录包含：

- `search_plan.json`：候选、分组、运行版本、输入及代码哈希，在训练前生成。
- `split_membership.csv`：544 个 trial_id 的 session、run、block、标签和新划分。
- `input_audit.json`：本次首次实验额外保存的数据唯一性和质量标记审计。
- `validation_search.csv`、`candidates/`：每个候选的验证成绩、完整训练历史和权重。
- `selection_before_test.json`：测试前固化的模型选择。
- `selected_model/model.pt`：完整最终模型成员、输入定义及训练集统计量。
- `selected_model/metrics.json`、`test_predictions.csv`：主测试指标及全部试次概率；另有未标记子集的描述性指标，不替代全体测试指标。
- `selected_model/training_curves.png`、`test_confusion_matrix.png`：训练曲线和测试混淆矩阵；混淆矩阵行是真实目标，列是预测目标。集成时曲线展示首个成员。
- `standard_baseline/`、`test_summary.csv`：完整搜索模式下的原始 EEGNet 基线对照。

## 环境及检查

项目内 `.venv` 复用 conda `pytorch` 的 GPU 版 PyTorch，并安装独立的 NumPy 1.26.4，避免原 conda 环境中的 NumPy 兼容问题。实际版本为 Python 3.9.21、PyTorch 2.7.0+cu126、NumPy 1.26.4、SciPy 1.13.1，GPU 为 GTX 1650。

如需重建环境：

```bash
conda activate pytorch
python -m venv --system-site-packages .venv
.venv/bin/python -m pip install --ignore-installed --no-deps numpy==1.26.4
```

运行六项检查：

```bash
.venv/bin/python -m unittest discover -s tests -v
```

检查完整会话/run 隔离、CSV 逆序及重复主键、V 到 μV 转换与逐试次处理、验证数据不影响训练统计量、合成频率含义、各模型反向传播和保存变换一致性。测试改写仅发生在临时副本，不修改数据包。

结果属于当前固定会话划分的离线监督分类。高分类准确率本身不等于光电/硬件同步已校准，也不能单独证明模型只利用了神经源 SSVEP；在线控制及新的独立采集尚需另外评价。
