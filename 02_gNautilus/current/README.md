# 同一人三次采集合并：EEGNet 四分类

整理后的入口为 `02_gNautilus/current/`；原g.Nautilus工程已整体移动，运行命令在当前目录执行。早期逐文件结果已单独归档。

根据最新说明，S01、S02、S03 是**同一个人的三次采集**。三份 accepted 4 秒数据已合并训练，仅用训练和验证集比较九组配置，再对所选架构检查三个固定随机种子。最终选择 **EEGNet 时空卷积骨干＋对数能量分类头**，合并测试准确率 **90.53%（86/95）**，宏 F1 **0.9049**。

## 快速使用

只训练最终配置，不重新执行完整搜索：

```bash
.venv/bin/python train_merged_final.py
```

入口 `train_merged_final.py` 按六个步骤组织，均有中文注释。每次运行新建带时间戳的结果目录，不覆盖此前实验。完整搜索代码在 `train_merged_eegnet.py`；如需重跑搜索，指定一个新的目录：

```bash
.venv/bin/python train_merged_eegnet.py --output-dir results/another_merged_search
```

对新信号做预测：

```bash
.venv/bin/python predict_merged_eegnet.py \
  --input 你的信号.npz \
  --output results/new_predictions.csv
```

输入 NPZ 只需含 `X`，形状 `[N,8,1000]`，单位 μV、采样率 250 Hz，通道及预处理定义与训练数据相同；`trial_ids` 可选。推理不读取真实标签或刺激频率元数据。默认加载本次模型 `results/eegnet_merged_search/selected_model/model.pt`，也可通过 `--model` 指定其他模型。

## 划分与数据处理

保留三次采集各自的原始区组划分后合并：

| 采集编号 | 训练：区组 1～5 | 验证：区组 6 | 测试：区组 7～8 |
| --- | ---: | ---: | ---: |
| S01 | 77 | 10 | 32 |
| S02 | 78 | 16 | 31 |
| S03 | 47 | 16 | 32 |
| 合计 | **202** | **42** | **95** |

- 以 NPZ `trial_ids` 一对一关联 `Metadata/Sxx_trials.csv`，按 `split` 取数据；不使用指向完整 128 行数组的 JSON 索引。
- 文件编号仅作为采集来源记录，不作为预测输入。没有随机重划分，也没有把同一试次的不同窗口分到不同集合。
- 只使用 `Sxx_accepted_0to4_uv.npz`，不混入 all 或 0.5～4 秒版本。
- 仅在训练集逐通道拟合均值和标准差，验证和测试沿用训练统计量。不根据测试成绩筛选试次或修改质量阈值。
- 原始单位已为 μV，不再次乘 `1e6`。固定通道为 PO7、PO3、POz、PO4、PO8、O1、Oz、O2。
- 标签为 0→A→6.5 Hz、1→B→9.0 Hz、2→C→11.5 Hz、3→D→14.5 Hz，表示注视目标类别。

数据已有采集端 30 Hz 低通、50 Hz 陷波和离线 4 Hz 零相位高通；未增加滤波，不将其描述为 4～90 Hz 宽带数据。accepted 是既有 500 μV 峰峰值规则的筛选结果，不代表人工确认完全无伪迹。

## 最终模型

最终模型的有效计算路径如下：

```text
标准化后的 [N,1,8,1000]
    ↓ 时间卷积：16 个滤波器，核长 251 点；BatchNorm
    ↓ 深度空间卷积：每个时间滤波器学习 2 个跨通道滤波器；BatchNorm
    ↓ 对时间维度做平方→均值→对数，得到 32 个能量特征
    ↓ Dropout 0.5
    ↓ 线性层：32→4，输出四类 logits
```

它保留 EEGNet 的时间卷积及深度空间卷积思想，以对数能量汇聚替代原来的可分离卷积及时间位置展平分类头，属于 **EEGNet 衍生变体，并非原版 EEGNet-8,2**。能量汇聚旨在减少对绝对相位和时间位置的依赖；本次组合修改的效果由验证及测试结果支持，未通过逐因素消融证明每项修改单独贡献多少。

相对第一轮原始配置：时间核从 125 点增至 251 点，时间滤波器从 8 增至 16，BatchNorm momentum 从 0.01 增至 0.1，分类器最大范数从 0.25 放宽为 0.5。使用 AdamW、学习率 0.001、weight decay 0.01、批量 32、Dropout 0.5、随机种子 42，最多 240 轮，早停等待 60 轮。以验证准确率优先、交叉熵次优选轮次，最后选中第 **231** 轮。

**最终模型只使用时域信号的可学习卷积特征，不使用 FFT 分支或候选频率评分。** 搜索中的频谱及融合候选仅作比较，其特征从每段信号同时计算四个候选评分，不接收该试次的真实刺激频率。

结构参考：[EEGNet 作者实现](https://github.com/vlawhern/arl-eegmodels/blob/master/EEGModels.py)；平方、平均和对数能量的背景见 [Schirrmeister 等原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5655781/)。项目未引入额外 EEG 模型库。

## 验证搜索

预先固定九组候选，以随机种子 42 比较；只使用训练和验证信号。纯频谱候选用于消融，不参与最终 EEGNet 类模型选择。

| 候选 | 最佳验证准确率 |
| --- | ---: |
| 合并后沿用原始 EEGNet | 35.71% |
| 加长时间核的 EEGNet | 92.86% |
| 对数能量汇聚 EEGNet | **100.00%** |
| 仅基频的共享频谱评分器 | 52.38% |
| 基频＋二次谐波评分器 | 76.19% |
| 非线性频谱评分器 | 78.57% |
| EEGNet＋平滑频谱 | 71.43% |
| EEGNet＋精确频点频谱 | 88.10% |
| 正则化更强的融合模型 | 71.43% |

选定能量汇聚架构后，再固定运行种子 43、44，各自最佳验证准确率为 97.62%、80.95%。三种子概率平均的验证准确率为 95.24%，低于最初种子 42 的 100%，因此最终使用种子 42 的单模型。不同种子表现有差异，训练结果尚未对初始化完全稳定。

选择结果先写入 `selection_before_test.json`，然后才评估合并原始基线和所选模型。未查看其他候选的测试成绩来决定模型。

## 固定测试集结果

| 模型 | 正确/总数 | 准确率 | 宏 F1 |
| --- | ---: | ---: | ---: |
| 三次采集合并，沿用原始 EEGNet | 29/95 | 30.53% | 0.2352 |
| 三次采集合并，最终能量汇聚模型 | **86/95** | **90.53%** | **0.9049** |

最终模型平衡准确率为 **90.625%**。按采集来源细分（仍是同一个合并模型）：

| 来源 | 正确/总数 | 测试准确率 |
| --- | ---: | ---: |
| S01 | 31/32 | 96.88% |
| S02 | 26/31 | 83.87% |
| S03 | 29/32 | 90.63% |

第一轮按三个文件分别训练的历史合并结果为 27/95=28.42%，因此只合并数据没有解决原始模型表现差的问题；本次最终模型相对本轮合并原始基线提高 **60.00 个百分点**。模型结构、优化及选轮次规则均有变化，不能将提升全部归因于其中一个因素。

这是同一人在三次采集的固定区组上的离线结果，未验证新采集会话或在线控制。95 个测试试次也曾用于第一轮历史基线，不是新增独立外部测试集；本轮调参未使用其成绩。

## 代码与产物

| 文件 | 用途 |
| --- | --- |
| `train_merged_final.py` | 推荐入口，只运行最终配置，六步中文说明 |
| `train_merged_eegnet.py` | 完整候选搜索、可调模型定义、验证选择及最终测试 |
| `predict_merged_eegnet.py` | 加载保存模型，预测无标签的新信号 |
| `train_eegnet.py` | 历史逐文件基线；提供数据核对、标准化及指标公共函数 |
| `tests/` | 数据对齐、划分隔离、预处理与模型检查 |

本次实际实验结果在 `results/eegnet_merged_search/`：

- `search_plan.json`：搜索前固定的候选、种子、划分、运行版本、输入和代码 SHA256。
- `split_membership.csv`：全部 339 个试次对应的采集、区组及划分。
- `validation_search.csv`：九组配置及另外两个种子的验证结果。
- `selection_before_test.json`：测试前固化的最终成员。
- `candidates/`：每次训练的权重、训练历史、验证概率及指标。
- `test_summary.csv`：合并原始基线与最终模型的测试对照。
- `selected_model/model.pt`：最终权重、训练集标准化参数和类别定义，推理直接使用。
- `selected_model/metrics.json`、`test_predictions.csv`：测试指标和全部 95 个试次的预测。
- `selected_model/training_curves.png`、`test_confusion_matrix.png`：训练曲线和混淆矩阵。

图中训练损失来自启用 Dropout 的批次，验证损失来自评估模式。最终模型按验证准确率优先选取，因此交叉熵未必最低。
